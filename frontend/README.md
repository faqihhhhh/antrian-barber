# Trimwait frontend

Antarmuka Trimwait dibuat dengan React, TypeScript, Vite, dan Tailwind CSS.

## Menjalankan secara lokal

1. Pasang Node.js 20.19+ atau 22.12+.
2. Dari folder `frontend`, jalankan `npm ci`.
3. Jalankan API Trimwait di `http://localhost:8080`.
4. Jalankan `npm run dev`, lalu buka alamat yang ditampilkan Vite.

Perintah pemeriksaan: `npm run build` dan `npm run lint`.
